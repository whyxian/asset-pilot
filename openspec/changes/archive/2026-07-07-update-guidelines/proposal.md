## Why

`GUIDELINES.md` 在实际使用中暴露了几个盲区：微变更走完整流程成本过高、归档流程没有提及 spec 同步、设计讨论的决策没有记录机制。

## What Changes

- 新增"微变更"快捷通道（跳过 design/specs）
- 归档流程补充 spec 同步检查
- 归档时机说明区分归档与 git commit
- 新增"记录关键决策"指引
- 微调措辞，补充实操经验
